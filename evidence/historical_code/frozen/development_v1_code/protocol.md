## 返回契约与布局

ordered_dense保持source_id/rid有序、原键及v/l/s矩阵；unordered_dense仅省去sort/take；unordered_arrow保留同逻辑列、类型、重复/全空记录和原生null。所有请求同投影值及LLI/SSI。查询接口query(request, contract, profile=False)，返回结果和seconds/scan_seconds/normalize_seconds；细阶段仅profile开启时记录。

核心W,C,Cstar,T,F。机制布局T_time,Tperm_time,Tperm_blocksv,C_2048,C_32768,C_full,W_packed。固定120min、8192行等原参数；2048/32768用于响应扫描。Tperm枚举行组行数向量的循环移位，最大化内部累计切分行号的绝对位移总和，平局最小移位；不参考性能。报告无变化文件、位移、跨时间块比例；改变文件覆盖记录不足80%时仅作探索性证据。C_full使用W对应站日完整schema；W_packed按固定星座顺序封装C_full原行组。实际压缩字节作为结果。

## 下游任务定义

六站×两个日期×30min/4h/24h×两任务=72请求。30min从站序0/3/6/9/12/15小时加330秒开始；4h对应整点；24h午夜。使用S类观测值及其LLI/SSI，不能将S码与SSI混同。时间保留源GPS日历标签。

时序表按站/星/码/时间/source_id/rid排序，保留重复、null和声明状态。缺测按站/星/码/5min统计实际存在观测记录内的已声明字段；未声明数量单列，分母0则比例null。不把全天每颗卫星都视为应可见，不计算整条历元缺失。单位由源头信息读取，缺失时标未声明，不补猜dB-Hz。比例验收rtol=1e-12、atol=1e-12；键/计数/空位置精确一致。所有契约走相同下游逻辑，转换/必要排序计入端到端时间。独立原始解析及独立标量参考在计时外。

## 正确性与分析

原有序输出按真值行数/指纹核验；无序在计时外规范排序后核验；Arrow用统一null/类型规则规范化。覆盖负零、重复、全空、缺码、空请求、flags空白与0、跨日及不支持语义。行组对照核验完整记录流、逐列值、null、浮点位及匹配组。元数据候选字节不当实际磁盘读取量。

正常每请求三次中位数，阶段分解选总时长中位数对应的同次调用；区组内配对，报告G/A/B、逐值、范围、Q1-Q6及空/非空。E4每模式两次的中位数配对，只有六区组G及B偏移均≤5%时定量解释细阶段。正常粗扫描/整理不受该门槛删除。

负载为六类0.2步长的252个单纯形点+等权点，另复现102个原alpha点。先区组内加权A或logG，再取六区组几何中心。3%近优集合中按total_bytes、files、布局ID字典序选择；同时报告1%/5%。报告固定各布局与条件推荐的平均/最大额外成本，不把权重点当独立样本。

新增布局按同测核心最好值筛选：成本中心降低≥5%且至少5/6同向，或成本在最好值3%内且空间减少≥5%。先在D1补齐全部CPU/契约（同测全部核心基线），再冻结D2候选及预测。筛选仅用D0/D1；在D2性能测量前写出带输入/代码hash的冻结凭据，D2用于验证不回调参数。未观察收益亦完整报告。
